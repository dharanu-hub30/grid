# WindWave – Harnessing Wind Energy for Smart Cities

A responsive image-gallery website built with HTML, CSS Grid and a little JavaScript.

## Files
| File | Purpose |
|------|---------|
| `index.html` | Main page (must keep this name – Vercel/GitHub Pages look for it) |
| `windwave-styles.css` | Styling and the CSS Grid responsive gallery |
| `windwave-gallery.js` | Lightbox + animated counters |
| `windwave-assets/` | 8 gallery images (`windwave-img-*.svg`) |

## Run locally
Open `index.html` in a browser.

## Deploy
Push to GitHub, then import the repo in Vercel (Framework Preset: **Other**, no build command).
